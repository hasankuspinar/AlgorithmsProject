# Independent Set Problem Analysis

This project focuses on solving the **Independent Set Problem** in graph theory. The goal is to find the largest subset of vertices in a graph where no two vertices are connected by an edge.

### What Was Done:
1. **Problem Formulation**: Described the Independent Set Problem and its real-world applications.
2. **Algorithm Development**:
   - A **Brute Force Algorithm** was implemented to guarantee optimal solutions.
   - A **Heuristic Algorithm** was designed to find approximate solutions efficiently for large graphs.
3. **Implementation**: Developed the algorithms in Python, including tools to generate graphs and visualize results.
4. **Performance Analysis**: Compared the runtime and quality of both algorithms experimentally.
5. **Correctness Testing**: Conducted tests to ensure the algorithms work correctly for various graph types.
6. **Conclusion**: Demonstrated that the heuristic algorithm offers a practical trade-off between speed and accuracy for solving large instances of the problem.

### Outcome:
The project provides a detailed analysis and comparison of two approaches to solve the Independent Set Problem, highlighting the efficiency and applicability of the heuristic algorithm for real-world scenarios.
